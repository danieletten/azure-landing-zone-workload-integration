# Security Policy

This is a community project that provides documentation-based Agent Skills. It
does not ship runtime services or deploy infrastructure on your behalf.

## Reporting a vulnerability

If you believe you have found a security issue in this repository (for example,
guidance that could weaken a security posture, or an unsafe example), please open
a private security advisory via GitHub's "Report a vulnerability" feature on this
repository, or contact the maintainers.

Please do not disclose potential security issues in public issues until they have
been reviewed.

## Scope and disclaimer

- The skills in this repository provide **guidance only**. They must be validated
  against your organization's Azure platform standards before use.
- Nothing here constitutes an official Microsoft or GitHub security control.
- The skill instructs the agent never to weaken or bypass a security control
  merely to make a deployment succeed, and never to change live Azure resources
  without explicit user authorization.
- Do not rely on example configurations as production-ready without review.
